# Shopify Pricing

Ιδιωτικός πίνακας τιμολόγησης για ένα Shopify store, με ελληνικό περιβάλλον, κανόνες ανά προμηθευτή και εγκατάσταση Docker / Portainer.

## Λειτουργίες

- Συγχρονισμός όλων των προϊόντων και παραλλαγών, χωρίς εξάρτηση από SKU για την ταυτοποίηση (χρησιμοποιούνται Shopify variant IDs).
- Ανάγνωση πραγματικής αγοράς από **Cost per item** στο Shopify. Η αγορά καταχωρίζεται χωρίς εκπιπτόμενο ΦΠΑ, στο βασικό νόμισμα EUR.
- Κανόνας ανά **Vendor**: προσαύξηση %, σταθερό καθαρό ποσό €, προαιρετική προσθήκη ΦΠΑ και συντελεστής.
- Πρόσθετη καθαρή χρέωση ανά παραλλαγή, π.χ. μεταφορική επιβάρυνση ογκώδους. Δεν πολλαπλασιάζεται με την προσαύξηση.
- Αναζήτηση, φίλτρα, επιλογή έως 100 παραλλαγών, προεπισκόπηση και ρητή εφαρμογή επιλεγμένων τιμών.
- Έλεγχος τιμής/κόστους/στοιχείων στο Shopify αμέσως πριν από την αποθήκευση. Συγκρούσεις παραλείπονται και καταγράφονται.
- Ιστορικό αποτελεσμάτων, χωρίς αυτόματη επανάληψη αποτυχημένων ή αβέβαιων εγγραφών.
- Καρτέλα API settings με έλεγχο σύνδεσης και κρυπτογραφημένη αποθήκευση μυστικών.

Δεν περιλαμβάνονται ιδιωτικοί τιμοκατάλογοι ή εμπορικοί όροι στο repository. Οι κανόνες αποθηκεύονται στη δική σας εγκατάσταση.

## Υπολογισμός τιμής

```text
βάση = καθαρή αγορά × (1 + προσαύξηση / 100)
       + σταθερό ποσό κανόνα
       + πρόσθετη καθαρή χρέωση παραλλαγής

τελική τιμή = βάση × (1 + ΦΠΑ / 100), αν ενεργοποιηθεί η προσθήκη ΦΠΑ
τελική τιμή = βάση, διαφορετικά
```

Παράδειγμα αγοράς 60€, προσαύξησης 55%, σταθερού ποσού 1€:

| Επιλογή | Τελική τιμή |
|---|---:|
| Με προσθήκη ΦΠΑ 24% | 116,56€ |
| Χωρίς προσθήκη ΦΠΑ | 94,00€ |

Τα ποσά και τα ποσοστά δέχονται δύο δεκαδικά, με τελεία ή κόμμα. Η τελική τιμή στρογγυλοποιείται στο λεπτό με εμπορική στρογγυλοποίηση, χωρίς ενδιάμεση στρογγυλοποίηση των πράξεων. Στις πρόσθετες χρεώσεις βάζουμε **καθαρό κόστος**, π.χ. 25€, όχι 31€, όταν η εφαρμογή θα προσθέσει 24% ΦΠΑ.

Η εκτίμηση υπολοίπου αφαιρεί από την καθαρή πώληση την αγορά και την πρόσθετη χρέωση προϊόντος. **Δεν είναι καθαρό κέρδος επιχείρησης**: λείπουν λοιπά μεταφορικά, προμήθειες, συσκευασία, διαφήμιση, πάγια και φόρος εισοδήματος. Ο συντελεστής του κανόνα χρησιμοποιείται για την εκτίμηση ελληνικής πώλησης με ενσωματωμένο ΦΠΑ, εφόσον το προϊόν είναι taxable στο Shopify. Η απενεργοποίηση της *προσθήκης* ΦΠΑ δεν καθιστά την πώληση αφορολόγητη.

## Εγκατάσταση στο Portainer — Docker Standalone

Το Portainer χρησιμοποιεί **έτοιμο container image**. Δεν χρειάζεται να χτίζει την εφαρμογή κατά το deploy από Git.

### 1. Έλεγξε το container build

Στο GitHub → **Actions → Test and publish container** πρέπει να έχει ολοκληρωθεί επιτυχώς το πρώτο workflow. Εκτελεί τους ελέγχους και δημοσιεύει image για `linux/amd64` και `linux/arm64`:

```text
ghcr.io/dkouskousis/shopify-pricing:latest
```

Για να μπορεί το Portainer να το κατεβάζει χωρίς registry credentials, έλεγξε στο GitHub profile → **Packages → shopify-pricing → Package settings → Change visibility → Public**. Νέα packages μπορεί να είναι private ακόμη και όταν το repository είναι public. Εναλλακτικά, κράτησε το package private και πρόσθεσε το GHCR ως authenticated registry στο Portainer με token που έχει `read:packages`. Μην ανεβάζεις tokens στο Git.

### 2. Δημιούργησε stack από Git

Portainer → **Stacks → Add stack → Repository**:

| Πεδίο | Τιμή |
|---|---|
| Name | `shopify-pricing` |
| Repository URL | `https://github.com/dkouskousis/shopify-pricing` |
| Repository reference | `refs/heads/main` |
| Compose path | `docker-compose.yml` |

Στο **Environment variables** πρόσθεσε:

| Variable | Τι βάζεις |
|---|---|
| `APP_URL` | Την ακριβή διεύθυνση, π.χ. `https://pricing.flerys.com`, χωρίς path |
| `APP_PASSWORD` | Ισχυρό μοναδικό password, τουλάχιστον 16 χαρακτήρες |
| `ENCRYPTION_KEY` | 64 δεκαεξαδικούς χαρακτήρες, δημιουργημένους μία φορά με `openssl rand -hex 32` |
| `APP_PORT` | `3180` ή άλλη διαθέσιμη θύρα |
| `BIND_IP` | `127.0.0.1` όταν το Plesk/reverse proxy είναι στον ίδιο host |
| `IMAGE_TAG` | `latest` ή συγκεκριμένο immutable tag `sha-…` από το workflow |

Πάτησε **Deploy the stack**. Τα Shopify credentials συμπληρώνονται μετά από login στην καρτέλα **Ρυθμίσεις API**· δεν χρειάζονται ως μεταβλητές stack.

Αν Docker και Plesk είναι σε διαφορετικούς servers, όρισε `BIND_IP` στη διεύθυνση LAN/VPN του Docker host που βλέπει το Plesk και επέτρεψε πρόσβαση στη θύρα μόνο από τον proxy. Μην αφήνεις τη θύρα της εφαρμογής δημόσια προσβάσιμη χωρίς HTTPS.

### 3. Plesk / HTTPS

Δημιούργησε subdomain με έγκυρο SSL και reverse proxy προς `http://127.0.0.1:3180` (ή τη διεύθυνση LAN του Docker host). Το subdomain πρέπει να έχει το ίδιο origin με το `APP_URL`.

Παράδειγμα nginx **για dedicated reverse-proxy virtual host**:

```nginx
location / {
    proxy_pass http://127.0.0.1:3180;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto https;
    proxy_read_timeout 90s;
}
```

Μην επικολλήσεις δεύτερο `location /` αν το Plesk δημιουργεί ήδη αντίστοιχο block. Ρύθμισε το subdomain ως reverse proxy με βάση τη διαμόρφωση του συγκεκριμένου server. Η εφαρμογή δεν εμπιστεύεται `X-Forwarded-For` για το rate limit, οπότε οι προσπάθειες login πίσω από έναν proxy μοιράζονται το ίδιο όριο.

## Shopify API settings

### Προτεινόμενο: Client credentials για δικό σου κατάστημα

1. Δημιούργησε εφαρμογή στο [Shopify Dev Dashboard](https://dev.shopify.com/).
2. Πρόσθεσε scopes **`read_products`, `read_inventory`, `write_products`**, δημιούργησε/release την έκδοση και εγκατέστησέ τη στο store. Ο λογαριασμός που δίνει πρόσβαση πρέπει να μπορεί να βλέπει το κόστος προϊόντων.
3. Η εφαρμογή και το store πρέπει να ανήκουν **στον ίδιο οργανισμό Shopify**. Η μέθοδος δεν είναι γενικό OAuth για καταστήματα τρίτων.
4. Στην εφαρμογή Pricing → Ρυθμίσεις API βάλε το πραγματικό `…myshopify.com` domain, Client ID και Client secret.
5. Πάτησε **Αποθήκευση**, μετά **Έλεγχος αποθηκευμένης σύνδεσης** και μετά **Συγχρονισμός Shopify**.

Το access token λαμβάνεται στον server και ανανεώνεται πριν από τη λήξη του. Δεν εμφανίζεται στον browser.

### Εναλλακτικά: υπάρχον Admin API access token

Επίλεξε ρητά αυτή τη μέθοδο και καταχώρισε ένα token με τα ίδια scopes. Η εφαρμογή δεν μεταβαίνει αυτόματα σε άλλη μέθοδο πιστοποίησης και δεν ανανεώνει χειροκίνητα καταχωρισμένα tokens. Όταν λήξουν/ανακληθούν χρειάζεται αντικατάσταση.

Τα πεδία μυστικών παραμένουν κενά μετά την αποθήκευση. Κενό πεδίο σε επόμενη αποθήκευση **διατηρεί** το προηγούμενο μυστικό. Για αλλαγή χρησιμοποιείται νέα τιμή. Για άλλο Shopify store χρειάζεται ξεχωριστή εγκατάσταση/volume, ώστε να μη συνδυάζονται εμπορικά δεδομένα διαφορετικών καταστημάτων.

## Πρώτη χρήση

1. Συμπλήρωσε στο Shopify την καθαρή **Cost per item** ανά παραλλαγή.
2. Συγχρόνισε προϊόντα. Δεν γίνονται εγγραφές στο Shopify σε αυτό το βήμα.
3. Στους **Κανόνες προμηθευτών**, επίλεξε Vendor και όρισε προσαύξηση, σταθερό ποσό και επιλογή ΦΠΑ.
4. Στα ογκώδη πάτησε την πρόσθετη χρέωση της αντίστοιχης παραλλαγής και βάλε το καθαρό κόστος επιβάρυνσης. Αν μια χρέωση αφορά όλη την αποστολή, καταχώρισε την κατάλληλη αναλογία ανά τεμάχιο.
5. Έλεγξε υπολογισμούς, επίλεξε παραλλαγές, πάτησε **Προεπισκόπηση** και μετά **Εφαρμογή**.
6. Έλεγξε το ιστορικό. Σε αβέβαιο αποτέλεσμα κάνε νέο συγχρονισμό και έλεγξε το Shopify πριν ξαναστείλεις αλλαγή.

Κενή/μηδενική αγορά, ελλιπής κανόνας, αρχειοθετημένο προϊόν ή κόστος σε άλλο νόμισμα δεν επιτρέπουν εφαρμογή. Όταν η νέα τιμή φτάνει/ξεπερνά υφιστάμενη Compare-at price, η παραλλαγή μπλοκάρεται για έλεγχο στο Shopify.

Οι κανόνες αντιστοιχίζονται ακριβώς στο **Vendor**. Αν αλλάξεις το Vendor στο Shopify, χρειάζεται νέος κανόνας ή αντίστοιχη αλλαγή. Ο συγχρονισμός διατηρεί τους κανόνες και τις πρόσθετες χρεώσεις υπαρκτών παραλλαγών.

## Τι ενημερώνεται

Η εφαρμογή γράφει **μόνο το βασικό `price`** των επιλεγμένων παραλλαγών. Δεν γράφει stock, cost, taxable, Compare-at price, εκπτώσεις ή σταθερές τιμές Markets/catalogs. Αν το κατάστημα έχει αυτόματες εκπτώσεις ή ξεχωριστή τιμολόγηση ανά αγορά, η τελική τιμή πελάτη μπορεί να διαφέρει από τη βασική τιμή που βλέπεις εδώ.

Κάθε προεπισκόπηση λήγει σε 15 λεπτά και χρησιμοποιείται μία φορά. Αλλαγή κανόνα, API settings, πρόσθετου κόστους ή νέος συγχρονισμός ακυρώνει προηγούμενες προεπισκοπήσεις. Υπάρχει έλεγχος πριν από κάθε write, αλλά το Shopify δεν παρέχει εδώ ατομικό compare-and-set· απόφυγε παράλληλα jobs τιμολόγησης από άλλη εφαρμογή.

## Δεδομένα, πρόσβαση και backups

- Ένας διαχειριστής, με password από το Portainer. Session 8 ωρών, HttpOnly/SameSite cookies, Secure μέσω HTTPS, έλεγχος origin και CSRF.
- Οι ρυθμίσεις σύνδεσης κρυπτογραφούνται με AES-256-GCM. Το `ENCRYPTION_KEY` παραμένει εκτός βάσης και εκτός repository.
- Μόνιμη SQLite βάση στο named volume `pricing_data`, συνήθως με όνομα `<stack>_pricing_data` στο Portainer. Δεν χρησιμοποιούνται bind mounts μέσα στο Git checkout.
- **Κράτησε backup του volume και του encryption key.** Για απλό συνεπές filesystem backup σταμάτησε το container, πάρε ολόκληρο το volume (μαζί με τυχόν SQLite WAL αρχεία) και μετά ξεκίνα το container.
- Στο redeploy κράτησε το ίδιο volume και key. Αλλαγή password αποσυνδέει τις παλιές συνεδρίες με την επανεκκίνηση.
- Δεν υπάρχει αυτόματη αλλαγή τιμών, scheduled sync ή αυτόματο rollback. Το ιστορικό διατηρείται στη βάση· η οθόνη εμφανίζει τις τελευταίες 200 εγγραφές.
- Μία μόνο ενεργή replica ανά βάση. Δεν προορίζεται για Docker Swarm ή πολλαπλά containers που μοιράζονται SQLite.

## Ενημερώσεις

Με κάθε push στο `main`, το GitHub Actions εκτελεί tests και δημιουργεί νέο image. Στο Portainer κάνε **Pull and redeploy / re-pull image**. Ένα απλό pull του Git repository δεν εγγυάται ότι θα ανανεωθεί ένα ήδη cached `latest` image. Για επαναλήψιμες εγκαταστάσεις χρησιμοποίησε το `sha-…` tag του επιθυμητού commit στο `IMAGE_TAG`.

## Τοπική εκτέλεση / έλεγχοι

Απαιτείται **Node.js 24**. Δεν υπάρχουν npm dependencies.

```sh
npm run check
npm test
```

Για τοπικό build με Docker, αντιγράφεις το `.env.example` σε `.env`, συμπληρώνεις τιμές και εκτελείς:

```sh
docker compose -f docker-compose.yml -f compose.build.yml up -d --build
```

Για development χωρίς Docker, δώσε `APP_URL=http://localhost:3000`, `APP_PASSWORD`, `ENCRYPTION_KEY`, `DB_PATH=./data/pricing.sqlite` και εκτέλεσε `npm start`. Το HTTP επιτρέπεται μόνο για localhost/127.0.0.1. Η παραγωγική διεύθυνση απαιτεί HTTPS.
